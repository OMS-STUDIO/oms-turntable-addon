# OMS Turntable 360°

> Blender addon for automatic 360° turntable animation with direct MP4 export.  
> By **OMS Studio**

---

## Features

- 🔄 **Multi-object** — independent pivot per object, all animations play simultaneously
- 🎬 **Direct MP4 export** — no manual assembly, works on Blender 3 / 4 / 5
- ⚡ **3 render presets** — Fast (preview) / Normal (Tebex) / Ultra (TikTok 4K)
- 🖼 **Video or Image** — full animation or single frame PNG
- 🎯 **Apply to All** — sync settings across all pivots in one click
- 📋 **Duplicate** — copy turntable settings from one object to another
- 👁 **Hide/Show pivots** — toggle Empty visibility in viewport
- ⏱ **Custom FPS** — 24 / 30 / 60 fps directly from the panel
- 📁 **Custom filename** — name your output file directly
- 🗂 **Collapsible UI** — clean sidebar, nothing open by default

## Installation

1. Download `oms_turntable.py`
2. Open Blender → `Edit → Preferences → Add-ons → Install`
3. Select the file and enable it
4. Open the `N` panel in viewport → **OMS Studio** tab

---

## Usage

1. Select your object(s) in **Object Mode**
2. Click **🔄 Ajouter Turntable 360°**
3. Adjust settings in Animation / Rotation panels
4. Click **▶ Preview Tous** to preview all animations
5. Open **Rendu & Export** → choose quality → render
